# استكمال تصميم الموقع — دليل التركيب

## 1) الملفات اللي هتستبدلها بالكامل
انسخ الملفات دي فوق الموجودة في مشروعك بنفس المسار:

- `app/page.tsx`
- `app/layout.tsx`
- `app/globals.css`

## 2) ملفات جديدة (اعملها بنفس المسار بالظبط)

- `lib/content.ts`
- `components/SiteHeader.tsx`
- `components/SiteFooter.tsx`
- `components/MajlisInterestModal.tsx`
- `app/not-found.tsx`
- `app/courses/page.tsx`
- `app/courses/[slug]/page.tsx`  ← لاحظ اسم الفولدر فيه أقواس مربعة [slug]
- `app/lessons/page.tsx`
- `app/lessons/[slug]/page.tsx`
- `app/articles/page.tsx`
- `app/articles/[slug]/page.tsx`
- `app/library/page.tsx`

`lib/supabase.ts` متلمسوش، هو زي ما هو.

## 3) الخطوة الوحيدة اللي لازم تعملها يدويًا
افتح **Supabase Dashboard → SQL Editor** وشغّل محتوى الملفات `supabase/site_content.sql` و`supabase/majlis_interest.sql` و`supabase/newsletter_subscribers.sql` و`supabase/academy_media.sql` و`supabase/member_accounts_notifications.sql` ثم `supabase/owner_roles_drafts.sql` مرة واحدة. قبل التشغيل استبدل `owner@example.com` ببريد حساب المالك الموجود لديك في الملفات التي تحتوي عليه. الأول يجهز المحتوى المنشور وسياسة الحفظ، والثاني يستقبل تسجيلات "سجّل اهتمامك"، والثالث يستقبل اشتراكات النشرة البريدية، والرابع ينشئ مساحة رفع ملفات الدروس والكتب من لوحة المالك، والخامس يفعّل حسابات الأعضاء وإشعارات المالك، والأخير يضيف المشرفين والمسودات والحماية الموحدة.

من غيرها، زرار "سجّل اهتمامك" هيدّي رسالة خطأ لما حد يحاول يسجل.

## 4) اللي اتصلح فعليًا

| الزرار | قبل | دلوقتي |
|---|---|---|
| عرض كل الدورات / فتح دورة | مالوش أي أكشن | صفحة `/courses` + صفحة تفصيلية لكل دورة مع دروسها |
| استمع ← (درس) | مالوش أي أكشن | صفحة `/lessons/...` — بتشغّل الصوت لو مضاف رابط، أو بتقول "قريبًا" بصدق بدل ما توهم إنها شغالة |
| اقرأ المقال ← | مالوش أي أكشن | صفحة `/articles/...` بمحتوى المقال كامل |
| تحميل ↓ (مكتبة) | مالوش أي أكشن | تحميل فعلي لو الرابط مضاف، أو حالة "قريبًا" واضحة |
| سجّل اهتمامك ← | مالوش أي أكشن | نافذة تسجيل بتحفظ في Supabase (بعد خطوة الـ SQL) |
| لوحة المالك | شغالة في الرئيسية بس | تفتح من أي صفحة (بترجعك للرئيسية وتفتح اللوحة تلقائيًا) |
| React.ReactNode في layout.tsx | خطأ TypeScript | متصلح |

## 5) إضافة محتوى حقيقي (اختياري، من لوحة المالك)
لكل صف بتضيفه في مربعات "الدروس / المقالات / المكتبة" داخل لوحة المالك، تقدر تضيف حقل إضافي اختياري آخر السطر بعد `|`:

- **درس:** `العنوان | التفاصيل | رابط الملف الصوتي`
- **مقال:** `العنوان | التصنيف | زمن القراءة | فقرة أولى\nفقرة ثانية\nفقرة ثالثة` (لاحظ `\n` بين الفقرات)
- **كتاب:** `العنوان | الوصف | رابط تحميل مباشر (PDF)`

لو سبتها فاضية، الصفحة هتعرض حالة "قريبًا" بدل ما توهم إن الملف موجود.

## 6) لوحة المالك الجديدة

بعد تسجيل الدخول من زر «لوحة المالك»، ستجد تبويبات منفصلة للإعدادات والدورات والدروس والمقالات والكتب، بالإضافة إلى المشتركين وطلبات الاهتمام والنسخ الاحتياطي. يمكنك إضافة وحذف العناصر وتعديلها، ورفع ملف صوتي أو PDF أو صورة غلاف للمقال مباشرة من البطاقة، وربط كل درس بدورته بشكل صريح، وتعديل نصوص الواجهة والألوان وبيانات التواصل ورمز العلامة، وإظهار أو إخفاء أقسام الصفحة الرئيسية بدون لمس الكود. بعد الرفع اضغط «حفظ ونشر للجميع» حتى يظهر الرابط للزوار. ومن تبويب النسخ الاحتياطي يمكنك تنزيل ملف JSON كامل أو استيراده محليًا ومراجعته قبل النشر.

داخل كل بطاقة محتوى توجد أزرار لتحريك العنصر لأعلى أو لأسفل، ونسخ عنصر مشابه بسرعة، ثم حفظ الترتيب الجديد مرة واحدة.

تمت إضافة صفحة بحث عامة من زر العدسة في الهيدر، ومشاركة مباشرة للمقالات والدورات والدروس عبر تيليجرام وواتساب أو نسخ الرابط.

كل عنصر محتوى يمكن الآن تعيينه ليظهر أو يختفي من الصفحة الرئيسية فقط، مع بقائه متاحًا في صفحته الكاملة.

للزائر أدوات «حفظ للمراجعة» و«علّمه كمكتمل» داخل صفحات المحتوى، وقسم «تابع من حيث توقفت» يظهر تلقائيًا في الرئيسية على نفس الجهاز.

تمت إعادة صقل التصميم بصريًا: هيدر ثابت شفاف، بطاقات وظلال وتفاعلات محسنة، خلفيات زخرفية هادئة، حالات تركيز أفضل، تصميم موبايل أقوى، ودعم تقليل الحركة لمستخدمي إعدادات الوصول.

في الإصدار الأحدث تمت إعادة بناء الهوية البصرية للموقع بالكامل: هيرو أكثر جرأة، هيدر زجاجي، بطاقات محتوى حديثة، أقسام دروس ومقالات ومكتبة بنظام موحد، مجلس ونشرة بتباين أقوى، وتنسيق موبايل أكثر وضوحًا. كما أصبحت خريطة المجتمع تعرض ملامح القارات وحدودًا داخلية وأسماء الدول بجوار النقاط بدل الترقيم.

تغيرت البنية أيضًا: الصفحة الرئيسية أصبحت مقسمة إلى هيرو بصري، مؤشرات سريعة، رف متابعة، ومسارات محتوى ببطاقات جديدة. صفحات الدورات والدروس والمقالات والمكتبة تستخدم مقدمة كتالوج مستقلة مع عدد العناصر، شريط بحث وفلاتر، وبطاقات مختلفة حسب نوع المحتوى.

في الإصدار التالي أصبح شريط الرئيسية تنقلًا فعليًا إلى صفحات المحتوى بدل تكرار الأقسام كاملة داخل الصفحة. الرئيسية تعرض بوابة مختصرة للأقسام فقط، بينما تعرض الصفحات الداخلية المحتوى كاملًا. خريطة المجتمع تعرض نقطة واسم الدولة المسجلة فقط، مع طبقة تضاريس مرئية داخل القارات.

أضيف إلى لوحة المالك تبويب «التحكم والظهور» بمفاتيح تشغيل وإخفاء فعلية للهيرو والكرة والبحث والمؤشرات وبوابة الأقسام والمحتوى المحفوظ والأقسام والفوتر وشريط الهاتف وزر أعلى الصفحة وتقدم القراءة، مع استمرار تعديل النصوص والألوان من تبويب مستقل.

أضيف إلى لوحة المالك «استوديو مظهر» للتحكم في كثافة المساحات (واسع / متوازن / مضغوط)، وشكل الحواف (ناعم / مستدير / حاد)، وزر الرجوع لأعلى. هذه الاختيارات تُحفظ مع إعدادات الموقع وتظهر تلقائيًا لكل الزوار، مع زر رجوع عائم يظهر بعد النزول في الصفحة.

أضيف أيضًا شريط تقدّم قراءة اختياري داخل صفحات الدروس والمقالات والدورات، مع فحص صحة المحتوى داخل «نظرة عامة» ينبه المالك إلى الدروس التي بلا صوت، والكتب التي بلا PDF، والمقالات التي بلا نص قبل النشر.

أصبحت صفحات الدورات والدروس والمقالات والمكتبة تحتوي على بحث فوري داخل الصفحة، وفلاتر للمستوى أو التصنيف عند توفرها، وعدّاد للنتائج ورسالة واضحة عند عدم وجود تطابق.

تحسنت مساحة العضو أيضًا: يمكن طلب رابط استعادة كلمة المرور من شاشة الدخول، ومعرفة عدد العناصر المحفوظة والمكتملة، والانتقال مباشرة إلى رف المحتوى المحفوظ بعد تسجيل الدخول.

أضيف من لوحة المالك تحكم في شكل الأزرار (كلاسيكي / بيضاوي / بإطار)، وإظهار أو إخفاء شريط التنقل السريع في الهاتف. الشريط يظهر أسفل الشاشة على الموبايل فقط للوصول السريع إلى الرئيسية والدورات والدروس والبحث والحساب.

أضيف وضع ليلي كامل: المالك يحدد الوضع الافتراضي من لوحة الإعدادات، والزائر يستطيع التبديل بين النهاري والليلي من زر صغير في الهيدر، ويُحفظ اختياره على جهازه.

الدروس تدعم الآن رابط أو رفع فيديو بجانب الصوت، ويظهر الفيديو داخل صفحة الدرس مع مشغل مناسب للموبايل. الحد الأقصى لرفع فيديو الدرس 200 ميجابايت.

أصبح ترتيب أقسام الصفحة الرئيسية قابلًا للتحكم من لوحة المالك؛ يمكن تحريك التعريف، مجتمع الدول، الدورات، الدروس، المجلس، المقالات، المكتبة والنشرة لأعلى أو لأسفل ثم نشر الترتيب الجديد لجميع الزوار.

أصبحت نصوص الواجهة الأساسية قابلة للتعديل من لوحة المالك: أسماء روابط التنقل، زر لوحة المالك، زر الإعلان، أزرار الهيرو، العدادات، عناوين وروابط الأقسام، نصوص البحث، حالات عدم وجود النتائج، أزرار الاستماع وقراءة المقال والتحميل، أزرار المكتبة والنشرة، نصوص البطاقة العائمة، مسميات البريد وتيليجرام وواتساب وإنستجرام ويوتيوب وحقوق النشر. نفس الإعدادات تُستخدم في الصفحة الرئيسية وصفحة البحث والفوتر حتى لا تحتاج تعديل الكود لتغيير الهوية أو العبارات.

تمت إضافة زر «دخول / حساب» للزوار. يستطيع الزائر إنشاء حساب بالبريد وكلمة المرور، وتظهر الحسابات الجديدة للمالك داخل تبويب «المشتركون والاهتمام» مع إشعار فوري بالتسجيل (وتحديث تلقائي كل 30 ثانية). كما تظهر إشعارات اشتراكات النشرة وطلبات اهتمام المجلس في نفس المكان. الحساب العادي لا يفتح لوحة المالك؛ فتح لوحة الإدارة يتطلب حساب المالك الذي تم وضعه في سياسة Supabase.

عند تشغيل ملف SQL الجديد تتم مزامنة «حفظ للمراجعة» و«علّمه كمكتمل» مع حساب العضو بين الأجهزة، مع الاحتفاظ بنسخة محلية حتى تظل التجربة تعمل إذا لم تتوفر الشبكة.

أضيفت كرة أرضية واحدة فقط داخل الـHero لمجتمع الأكاديمية، مع لوحة دول متصلة أسفل الصفحة بدل تكرار الكرة. عند إنشاء الحساب يختار العضو دولته، وتظهر للعامة أسماء الدول وعدد الأعضاء بشكل مجمع فقط، بينما يظل البريد والاسم ظاهرين للمالك داخل لوحة الإدارة. إذا لم ترغب في عرض قسم المجتمع، أوقف خيار «إظهار خريطة مجتمع الدول» من إعدادات المالك.

تم تجديد الكرة بصريًا لتظهر كواجهة ثلاثية الأبعاد داكنة بملامح قارات واضحة، مع شبكة خطوط منحنية ورؤوس أسهم تربط كل الدول التي ظهرت في إحصائيات التسجيل. تظل الكرة واحدة داخل الهيرو، بينما تعرض لوحة المجتمع أسفلها قائمة الدول والأعداد بدون تكرار الكرة.

## 7) ملاحظة على إصدار Next.js
الكود مكتوب على افتراض **Next.js 15** (حيث `params` في الصفحات الديناميكية بيكون `Promise` لازم تعمله `await`) — استنتجت ده من وجود `next.config.ts` عندك. لو ظهر خطأ عن `params` وقت البناء، يبقى نسختك أقدم، وهيبقى الحل إنك تشيل `await` وتستخدم `params.slug` مباشرة في الملفات اللي فيها `[slug]`.

## 8) اللي متأجل عمدًا (مش "شغال" بس مقبول كـ v1)
- نموذج النشرة البريدية يحفظ البريد داخل Supabase وتقدر تراجعه من تبويب «المشتركون وطلبات الاهتمام». إرسال رسائل جماعية يحتاج ربط خدمة بريد لاحقًا (Mailchimp/Brevo/غيره).
- زرار "لوحة المالك" في الصفحات الفرعية بيرجعك للرئيسية بدل ما يفتح مباشرة في مكانه — قرار لتقليل التعقيد، ممكن نطوره بعدين لو حبيت.

## 9) رفع التحديثات إلى GitHub

بعد فك آخر ملف فوق مشروعك وفتحه في VS Code، افتح Terminal داخل مجلد المشروع وشغّل:

```bash
git add -A
git commit -m "Update academy design and owner controls"
git push origin main
```

لو ظهر أن GitHub فيه تحديثات أحدث، نفّذ:

```bash
git pull --rebase origin main
git push origin main
```

لا ترفع ملف `.env.local` أو أي مفاتيح سرية. بعد نجاح `push` سيبدأ Vercel النشر تلقائيًا إذا كان المشروع مربوطًا بالمستودع.

## 10) ملاحظة عن صور المشاركة

تم جعل نصوص صور المشاركة آمنة لمحرك توليد الصور في Vercel. محتوى الموقع العربي نفسه لا يتغير؛ التنظيف يطبق على صورة المشاركة فقط حتى لا يتعطل البناء بسبب مشكلة Satori القديمة مع تشكيل العربية وـRTL.

## 11) الإصدار الكامل الجديد: الصلاحيات والمسودات وPWA

النسخة الكاملة المرفقة تشمل المشروع كاملًا، وليست Patch. بعد فك الضغط استبعدت منها `.git` و`node_modules` و`.next` وملفات `.env` حتى لا تتسرب أسرار أو ملفات ضخمة. نفّذ `npm install` ثم `npm run dev` أو ارفعها إلى GitHub كما هي.

شغّل ملف `supabase/owner_roles_drafts.sql` بعد ملفات Supabase السابقة. الملف يضيف:

- جدول `site_admins` بأدوار `owner` و`editor` و`viewer`.
- دالتي `is_site_admin()` و`site_admin_role()` لحماية لوحة الإدارة والرفع.
- جدول `site_content_drafts` لحفظ مسودة مرحلية على الحساب قبل النشر.
- سياسات موحّدة للمحتوى والإشعارات والأعضاء والملفات بدل الاعتماد على بريد المالك فقط.

داخل لوحة الإدارة ستجد زر «حفظ مسودة على الحساب»، كما تُحفظ نسخة محلية تلقائيًا أثناء الكتابة ويمكن استرجاعها من زر «استعادة المسودة المحلية». زر «حفظ ونشر للجميع» يحدّث النسخة المنشورة ويحذف المسودة المرحلية بعد نجاح النشر.

تمت إضافة `app/manifest.ts` و`public/sw.js` و`components/PwaRegister.tsx` لتثبيت الأكاديمية كتطبيق على الهاتف مع تشغيل أساسي دون اتصال للصفحات التي تمت زيارتها. لا تضع مفاتيح Supabase داخل ZIP؛ احتفظ بملف `.env.local` لديك فقط.

إذا فشل `next build` محليًا برسالة `spawn EPERM` على Windows بينما يمر TypeScript، فهذا قيد صلاحيات تشغيل worker في البيئة المحلية؛ جرّب البناء من Vercel أو شغّل الطرفية بصلاحيات مناسبة. وفي Vercel يجب التأكد من أن متغيرات Supabase موجودة في Environment Variables.
